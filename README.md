# 🐍 Snake Game

A classic Snake Game built using the **Godot Game Engine**. Control the snake, collect food, grow longer, and try to achieve the highest score without hitting the walls or yourself.

## 🎮 Gameplay

- Control the snake using the arrow keys.
- Eat food to increase your score and grow longer.
- Avoid colliding with your own body.
- Try to achieve the highest score possible!

## 🕹️ Controls

| Key | Action |
|---|---|
| ↑ Up Arrow and W| Move Up |
| ↓ Down Arrow and S| Move Down |
| ← Left Arrow and A| Move Left |
| → Right Arrow and D| Move Right |

## 🛠️ Built With

- **Game Engine:** Godot
- **Programming Language:** GDScript

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Heyitsmepranil/Snake-Game-Godot.git
   ```
